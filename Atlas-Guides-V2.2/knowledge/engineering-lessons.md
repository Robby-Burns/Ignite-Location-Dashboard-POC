# Atlas Guides — Engineering Lessons

## Purpose
Store durable, reusable engineering lessons promoted from verified project observations.

## Promotion Criteria

A lesson must be:

1. verified;
2. durable;
3. reusable across projects or domains;
4. actionable as a design, testing, or governance improvement.

## Lifecycle

```text
Observation
→ Pattern
→ Hypothesis
→ Recommendation
→ Test
→ Validated Lesson
→ Promotion Candidate
→ Approved Knowledge
```

Knowledge promotion is not part of the critical story execution path.

A lesson does not grant authority to change protected project behavior.
